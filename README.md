# Notion Widget

A small collection of AI-generated ambient browser widgets designed to add a little personality to a Notion command center or personal dashboard.

These are fully self-contained HTML files with no build step or external dependencies. Each scene is meant to be opened in a browser and used as a static visual widget, or adapted for embedding in a Notion setup.

## Included scenes

- `night-drive.html` — a rainy neon city at night with a moving car, reflective streets, and glowing lights.
- `sakura-lake.html` — a moonlit cherry blossom scene with drifting petals and a calm lake.
- `study-session.html` — a focused, cozy ambient scene built for a work or study vibe.

## How to use

1. Open any `.html` file in a browser.
2. If you want a widget-style experience, use your browser's full-page or screenshot workflow and embed it in Notion.
3. You can also customize colors, text, or animation timing directly in the file.

## Notes

- This project is intentionally lightweight and portable.
- The visuals are AI-generated and are meant to serve as creative mood pieces rather than production-ready apps.
